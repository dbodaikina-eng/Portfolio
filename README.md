# Portfolio — horizontal accordion

Живая страница: https://dbodaikina-eng.github.io/Portfolio/

## Что где

- `index.html` — готовая страница, один файл (картинки, скрипты, шрифты-ссылки внутри). Лежит в корне репозитория, GitHub Pages отдаёт его как главную.
- `src/` — исходники для правок: `Horizontal Accordion.dc.html`, `support.js`, `image-slot.js`, изображения, дизайн-система. Не обязательны для работы сайта.

## Как обновить

```
cp /path/to/new/index.html index.html
git add index.html
git commit -m "Update portfolio"
git push
```

Страница на GitHub Pages обновится через ~1 минуту.
